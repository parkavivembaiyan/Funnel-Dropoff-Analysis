# Funnel Drop-off Analysis

## Objective
Analyze the signup funnel by calculating:
- Unique users at each stage
- Conversion rate from the previous stage
- Biggest drop-off stage

## Result

| Stage | Unique Users | Conversion Rate |
|-------|-------------:|----------------:|
| Visited Site | 200 | 100.00% |
| Signup Started | 150 | 75.00% |
| Details Filled | 96 | 64.00% |
| Email Verified | 52 | 54.17% |
| Purchase Completed | 44 | 84.62% |

### Biggest Drop-off
Details Filled → Email Verified (45.83% drop-off)
